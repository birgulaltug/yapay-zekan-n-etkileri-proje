# yapay-zekan-n-etkileri-proje
yapay zekanın insanlar üzerindeki bireysel ve sosyal etkileri projesi
UML Diyagramlarının Kısa Açıklamaları
• 1. Use Case Diagram (Kullanım Durumu Diyagramı):
Sistemin dışarıdan bakıldığında ana aktör (Araştırmacı) ile hangi noktalarda etkileşime gireceğini, veri setlerinin yüklenmesi ve analiz süreçlerinin <<include>> ilişkileriyle alt adımlara nasıl bölündüğünü görselleştirmek amacıyla tasarlanmıştır.
• 2. Activity Diagram (Etkinlik Akış Şeması):
Verilerin sisteme yüklenmesinden başlayarak bireysel ve sosyal etki analizlerinin gerçekleştirilmesine, ardından sonuçların raporlanıp dışa aktarılmasına kadar geçen süreçteki mantıksal adım akışını ve ardışık işlem sırasını göstermektedir.
• 3. Class Diagram (Sınıf Diyagramı):
Sistemin arka planda hangi nesnelerle çalışacağını (Arastirmaci, EtkiAnalizMotoru, RaporlamaMerkezi), verilerin hangi sınıflar aracılığıyla işleneceğini ve bu sınıfların birbirleriyle olan öznitelik, metot ve mimari bağlarını modellemek amacıyla oluşturulmuştur.
